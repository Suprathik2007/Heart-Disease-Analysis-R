# Heart Disease Analysis Using R

## Overview

This project presents a complete data analysis workflow using the Heart Disease dataset.

The project was completed in four stages:

- Week 1 – Data Cleaning, Preprocessing and Exploratory Data Analysis
- Week 2 – Data Visualization
- Week 3 – Statistical Analysis and Predictive Modeling
- Week 4 – Comprehensive Data Analysis Report

## Dataset

The Heart Disease dataset contains patient-related variables such as age, sex, chest pain type, resting blood pressure, cholesterol, maximum heart rate, exercise-induced angina and heart disease status.

Dataset source:

https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset
